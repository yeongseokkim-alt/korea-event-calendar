# Korea Demand Event Calendar

## 목적

한국의 연휴, 지역 축제, 대형 공연·스포츠 경기, 전시·컨벤션 등 숙박 수요에 영향을 줄 수 있는 이벤트를 사전에 파악합니다. 이를 바탕으로 숙소 파트너가 적절한 시점에 객실 판매 가능 재고와 운영 계획을 점검하도록 돕습니다.

## 이 프로젝트가 제공하는 것

- 지역·기간별 주요 수요 이벤트 정보
- 이벤트의 예상 영향 권역과 준비 권장 시점
- 공식 출처를 바탕으로 한 행사 정보 검증 기록
- 행사 후 실제 결과를 반영한 운영 기준 개선

## 운영 원칙

1. 모든 이벤트는 공식 주최 측, 지자체 또는 신뢰할 수 있는 출처로 확인합니다.
2. 일정 변경·취소 가능성을 고려해 최종 확인일과 출처를 기록합니다.
3. 수요 영향은 `High Impact`, `Medium Impact`, `Low Impact`의 세 단계로 표시합니다.
4. 파트너에게는 가격 지시가 아니라 재고·판매 설정을 점검할 수 있는 정보와 근거를 제공합니다.
5. 개별 파트너, 예약 또는 고객의 민감한 데이터는 이 저장소에 저장하지 않습니다.

## 초기 범위

- 대상 지역: 서울, 부산, 제주
- 대상 이벤트: 국가 연휴, 대형 지역 축제, 대형 공연·스포츠, 전시·컨벤션
- 운영 주기: 향후 6개월 이벤트를 정기적으로 검토 및 갱신
